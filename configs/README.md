# FortiGate Configurations

These files are **sanitized configuration exports** prepared for public study and portfolio use.

## Files

- `fortigate/hq-cluster.conf` — Egypt HQ Active-Passive FortiGate HA configuration.
- `fortigate/libya-branch.conf` — Libya branch FortiGate configuration.
- `fortigate/tunisia-branch.conf` — Tunisia branch FortiGate configuration.

## Important

Sensitive material has been removed from the public versions, including credentials, IPsec pre-shared keys, private keys, and certificates.

Use these files as technical references. They are **not plug-and-play production configurations**. Any recreated lab must define its own secrets and environment-specific values before deployment.
